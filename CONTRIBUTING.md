# Contributing

Start with the simulator and offline test suite in the README. Keep changes focused and include a regression test. Never weaken manual takeover, no-autoarm, Stop/Land or heartbeat protections as part of an unrelated change. Document changes to those contracts explicitly.

Use generated fixtures only. Do not attach real scans, floor plans, recordings, home screenshots, browser profiles, personal radio backups or API keys. Strip image/PDF metadata and inspect the actual content before submitting. Retain third-party licenses; do not add model weights without verified redistribution rights.

Submit a pull request describing behavior, tests, privacy impact and any unverified hardware assumptions. No live-flight test is requested by CI. Report sensitive security issues privately as described in SECURITY.md.
